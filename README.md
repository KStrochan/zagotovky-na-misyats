# Заготовки на місяць

Лендинг PDF-гайду «Морозилка на місяць»: 20 заготовок, 4 списки покупок, правила заморозки.

Статичний сайт без збірки: HTML + CSS + JS-модулі, шрифти — у `fonts/`. Замовлення обробляє серверна функція Vercel `api/order.js`: вона надсилає покупцю лист із файлами через Gmail.

**Перший екран.** Статичний: заголовок, ціна і план «4 вихідні → 20 заготовок». Під ним — картки, що готується кожні вихідні. Без відео й анімацій, тож сторінка легка і швидко відкривається на телефоні.

## Оплата

Онлайн-еквайрингу немає, тому оплата в два кроки: покупець залишає email, бачить номер картки і платить переказом через EasyPay (комісія 1% + 5 грн з покупця), потім натискає «Я оплатив(ла)». Одразу після цього йому приходить лист із файлами у вкладенні, а вам — лист «Продаж», щоб звірити надходження на картці.

- Файли продукту лежать у `api/_files` зашифрованими (AES-256-GCM): репозиторій публічний, а без ключа `FILES_KEY` їх не відкрити. Що саме надсилається — у `api/_product.js`.
- Номер картки зберігається тільки в змінній `PAY_CARD` на Vercel — у репозиторії його немає.
- `DELIVERY=manual` — якщо хочете спершу перевіряти оплату: вам приходить лист із кнопкою «Підтвердити і надіслати файли», покупцю — «Перевіряємо оплату».
- Код — `assets/js/pay.js` (сторінка) і `api/order.js` (сервер).

## Деплой на Vercel

1. New Project → імпортуйте цей репозиторій. Framework Preset: **Other**, Build Command порожній, Output Directory — корінь.
2. Settings → Environment Variables:
   - `SMTP_USER` — Gmail, з якого йдуть листи (краще окрема скринька під бренд);
   - `SMTP_PASS` — пароль застосунку для цього Gmail: Google-акаунт → Безпека → Двоетапна перевірка → Паролі застосунків (16 символів, без пробілів);
   - `FILES_KEY` — ключ, що розшифровує файли продукту (отримуєте від розробника, однаковий для трьох сайтів);
   - `PAY_CARD` — номер картки, на яку покупці переказують гроші через EasyPay. Без нього форма працює як передзамовлення;
   - `OWNER_EMAIL` — куди надсилати сповіщення про продажі (необов'язково, за замовчуванням — `SMTP_USER`);
   - `DELIVERY` — `auto` (за замовчуванням) або `manual`.
3. Redeploy.

## SEO

- `title`, `description`, canonical, Open Graph і Twitter-картка (`img/og.png`, 1200×630).
- JSON-LD: Organization, WebSite, Product з Offer (`InStock`), FAQPage.
- `robots.txt`, `sitemap.xml`, `site.webmanifest`, favicon SVG.
- Шрифти віддаються з власного домену з довгим кешем, а CSS і JS — з перевіркою свіжості при кожному заході (`vercel.json`), щоб після оновлення ніхто не отримав стару версію скриптів.

**Якщо підключаєте свій домен** — замініть `https://zagotovky-na-misyats.vercel.app` на нього в `index.html`, `privacy.html`, `robots.txt` і `sitemap.xml`.

## Що доробити перед запуском реклами

- Вставити код Meta Pixel у `<head>` (місце позначене коментарем).
- Дописати контакти й дані продавця в `privacy.html`.
- Після реєстрації ФОП — замінити переказ через EasyPay на онлайн-оплату з автоматичною видачею файлу (WayForPay / LiqPay / plata by mono).
